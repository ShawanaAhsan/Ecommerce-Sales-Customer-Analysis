# Ecommerce-Sales-Customer-Analysis
E-commerce sales and customer analysis using Python, Pandas, NumPy, Matplotlib and Seaborn.
# E-Commerce Sales & Customer Analysis

## Project Overview

This project analyzes e-commerce transaction data using Python to identify patterns in sales, customer behavior, product categories, regional performance, payment methods, delivery time, discounts, and customer ratings.

## Objectives

* Analyze overall revenue performance
* Identify monthly revenue trends
* Compare product category performance
* Analyze regional sales
* Identify high-value customers
* Examine payment methods
* Analyze delivery performance
* Explore customer ratings
* Examine the relationship between discounts and revenue

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains information about:

* Orders
* Customers
* Product categories
* Regions
* Quantity
* Unit prices
* Discounts
* Payment methods
* Delivery days
* Customer ratings
* Revenue
